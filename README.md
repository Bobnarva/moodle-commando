# Moodle Commando

Скрипт для автоматизации и помощи в прохождении тестов на базе Moodle. Работает на основе связки облачной базы данных Firebase и мульти-провайдерного ИИ-решателя (**Gemini**, **Groq**, **OpenRouter**).

## Основные функции
* **Быстрая загрузка:** Интерфейс плашки появляется сразу при готовности каркаса страницы, не дожидаясь загрузки тяжёлых картинок или формул.
* **Автоматический сбор ответов:** При просмотре результатов теста (страница `review.php`) скрипт автоматически сохраняет правильные ответы в облачную базу Firebase и удаляет ошибочные записи.
* **Мульти-провайдерный ИИ-решатель:** Если вопроса нет в базе, его можно решить через нейросеть (поддерживаются текстовые вопросы, тесты со множественным выбором, короткий ввод, сопоставления и вопросы с изображениями). Поддерживаются бесплатные API-ключи **Google AI Studio (Gemini)**, **Groq** и **OpenRouter (`:free`)**.
* **Smart Auto и каскадный fallback:** Умная маршрутизация автоматически оценивает сложность вопроса (простой текст, средняя сложность или сложный вопрос с картинками) и подбирает оптимальную модель (`fast`, `medium` или `smart`). При лимитах (`429`), перегрузках или ошибках скрипт сам переключается на следующую доступную модель в цепочке.
* **Режим автопилота:** Кнопка автоматического последовательного решения и переключения страниц теста с подсчётом статистики по БД и ИИ.

## Установка

1. Установите расширение **Tampermonkey** в браузер.
2. Откройте в этом репозитории файл `commando.user.js`.
3. Нажмите кнопку **Raw** в верхнем правом углу панели с кодом.
4. В открывшемся окне Tampermonkey нажмите **Установить** (или *Обновить*).
5. *(Опционально)* Откройте панель **COMMANDO** на странице Moodle → нажмите **[ НАСТРОИТЬ КЛЮЧИ ]** и вставьте бесплатные API-ключи от **Gemini**, **Groq** (`gsk_...`) и/или **OpenRouter** (`sk-or-...`) для максимальной скорости и стабильности.

## Обновление
Обновление происходит автоматически в фоновом режиме через Tampermonkey по мере изменения версии (`@version`) в коде этого репозитория.
